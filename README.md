Консольный ассистент, который подбирает спектакли по лайкам и дизлайкам пользователя и понимает запросы на русском языке:
«Покажи все оперы и мюзиклы», «Поставь лайк Кормен» (с опечаткой), «Лайк 3, дизлайк 5. Что порекомендуете?».

Лабораторная работа по дисциплине «Системы искусственного интеллекта», кафедра ИУ7, магистратура МГТУ им. Н.Э. Баумана (осень 2025).

## Возможности

- **Рекомендации по сходству.** Для каждой постановки считается мера сходства с понравившимися и непонравившимися: категориальные признаки (жанр, стиль, театр, язык, аудитория) сравниваются по таблицам близости, числовые — по нормированному расстоянию, бинарные — на совпадение. Из этого строится рейтинг.
- **Фильтры на естественном языке.** Запрос разбирается на действие (лайк, фильтр, рекомендация, отмена…) и сущности (ID, название, жанр, театр, числовые условия) и превращается в фильтр `pandas`.
- **Нечёткие критерии.** Термы вроде «длинные», «не очень длинные», «средней продолжительности» задаются лингвистической переменной с функциями принадлежности и превращаются в числовые диапазоны.
- **Устойчивость к опечаткам.** Названия ищутся по расстоянию Левенштейна (`rapidfuzz`).
- **Морфология и синтаксис.** `pymorphy2` и `spaCy` приводят слова к нормальной форме и помогают выделить сущности.
- **История действий.** Можно отменить последний шаг или сбросить все фильтры и оценки.

## Быстрый старт

```bash
pip install -r requirements.txt
python -m spacy download ru_core_news_sm
python main.py
```

`main.py` проверяет зависимости (и предлагает доустановить недостающие), загружает `test.csv` из текущей папки и запускает диалог.

Запуск из ноутбука или Colab:

```python
import pandas as pd
from natural_language_interface import NaturalLanguageInterface

df = pd.read_csv("test.csv", decimal=",")
NaturalLanguageInterface(df).run()
```

## Примеры запросов

| Что нужно | Запрос |
|---|---|
| рекомендации | «Покажи топ-5 рекомендаций», «Какие пять лучших постановок вы мне порекомендуете?» |
| оценки + рекомендация | «Поставь лайк на 3, дизлайк на 5. Что порекомендуете?» |
| фильтрация | «Покажи все оперы и мюзиклы», «Найди постановки в театре Современник», «Найди длинные спектакли» |
| управление | «Сделай шаг назад», «Сбрось все фильтры и лайки» |

Полный список проверенных запросов — в [docs/queries.md](docs/queries.md).

## Устройство

```
main.py                         точка входа: проверка зависимостей, загрузка данных, запуск CLI
natural_language_interface.py   цикл диалога с пользователем
nlp_query_analyzer.py           связывает NLP-компоненты в один разбор запроса
├── action_tagger.py            какое действие просит пользователь
├── entity_extractor.py         ID, названия и критерии из текста
├── nlp_analyzers.py            морфологический и синтаксический анализ
└── query_to_filter.py          запрос → фильтр pandas
recommendation_system.py        лайки/дизлайки, меры сходства, рейтинг, история действий
criteria_tree.py                дерево критериев для иерархической фильтрации
linguistic_variables.py         нечёткие лингвистические переменные
fuzzy_matching.py               нечёткий поиск по названиям
config.py                       проверка, какие библиотеки доступны
test.csv                        датасет постановок
```

## Данные

`test.csv` — собственный датасет постановок: название, театр, режиссёр, жанр, стиль, язык, целевая аудитория, длительность, год, число антрактов, рейтинг, награды, признаки «на открытом воздухе», «платный», «семейный», «для детей», теги и темы.
